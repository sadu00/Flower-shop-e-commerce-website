# 🌸 Flora & Fleur - Online Flower Shop

Flora & Fleur is a full-stack web application designed for a modern flower shop. It allows users to browse handcrafted floral arrangements, place orders, and enables admins to manage products and customer orders seamlessly.

---

## ✨ Key Features

### 🛍️ Customer Facing Interface
* **Product Showcase:** Browse various flower arrangements categorized by occasions.
* **Interactive Cart:** Add items to cart and review prices dynamically.
* **Seamless Checkout:** Easy order placement with flexible payment options.

### 🔐 Admin Portal
* **Product Management (CRUD):** Add new flower arrangements, update existing ones, or delete products.
* **Order Tracking:** View customer order details, total amounts, and update delivery status (e.g., Pending, Completed).
* **Live Chat / Messages:** View and respond to customer queries directly from the admin dashboard.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose ODM)
* **Authentication:** JSON Web Tokens (JWT), bcrypt.js
